# Taqueria El Buchon — Official Website

The official website for **Taqueria El Buchon**, an authentic Mexican restaurant located in Staten Island, NY. Built and maintained by [Volta NYC](https://github.com/Volta-NYC).

🌐 **Live site:** [taqueria-el-buchonsi.vercel.app](https://taqueria-el-buchonsi.vercel.app)

📦 **Generated from:** [Volta-NYC/base-repo](https://github.com/Volta-NYC/base-repo)

---

## 🚀 Overview

This website serves as the official online presence for Taqueria El Buchon, showcasing the restaurant's menu, catering services, contact information, and brand identity. The site highlights the restaurant's authentic Mexican cuisine — from street tacos and burritos to soups, quesadillas, and fresh drinks — along with catering offerings for events such as birthday parties, school events, and showers.
